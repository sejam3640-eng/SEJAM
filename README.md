# SHAH JAM ACCESSORIES

A modern, luxury fashion e-commerce website showcasing premium accessories including watches, handbags, jewelry, and more.

## Features

✨ **Modern Design**
- Responsive layout with Tailwind CSS
- Elegant gold and white color scheme
- Smooth animations and transitions
- Mobile-friendly interface

🛒 **Shopping Functionality**
- Dynamic product catalog
- Shopping cart with local storage
- Add/remove items from cart
- Real-time cart updates
- Checkout functionality

📱 **User Experience**
- Mobile menu navigation
- Smooth scrolling
- Interactive FAQ section
- Contact form
- Testimonials section
- Fashion gallery
- Blog section

⚡ **Performance**
- Optimized images from Unsplash
- Lazy loading support
- Smooth scroll behavior
- Minimal dependencies

## Getting Started

### Prerequisites
- A modern web browser
- Node.js (optional, for development server)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sejam3640-eng/SEJAM.git
cd SEJAM
```

2. Open in browser (simple method):
```bash
Open index.html in your web browser
```

3. Or run with live server:
```bash
npm install
npm start
```

## Usage

### Adding Products to Cart
1. Click "Add to Cart" on any product
2. View cart by clicking the cart icon
3. Adjust quantities or remove items
4. Proceed to checkout

### Filling Contact Form
1. Scroll to the Contact section
2. Fill in your details
3. Submit the form
4. Receive confirmation notification

### FAQ Section
- Click on any FAQ item to expand/collapse answers
- Smooth animations for better UX
